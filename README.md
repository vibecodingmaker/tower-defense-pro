# Tower Defense Pro 🏰

A professional tower defense game built with Codex AI. Defend your base against waves of enemies by strategically placing towers!

## 🎮 Game Features

- **6 Unique Tower Types**: Arrow, Cannon, Ice, Lightning, Fire Dragon, and Dark Mage
- **3 Upgrade Levels**: Each tower visually evolves as it levels up
- **Wave System**: Progressively harder waves with various enemy types
- **Mobile-First Design**: Optimized for portrait mode on phones/tablets

## 🏗️ Built With

- Pure HTML5/CSS3/JavaScript (no external dependencies except Google Fonts)
- Canvas-based 60fps rendering
- Touch and mouse support
- Auto-deployed to Netlify

## 🎯 How to Play

1. Click a tower type in the bottom bar to select it
2. Tap on grass tiles to place towers (not on the path)
3. Click existing towers to upgrade or sell them
4. Earn gold by defeating enemies
5. Survive as many waves as possible!

Simply open `index.html` in any modern browser - no build step required.

## 📱 Layout

- **Top Bar (15%)**: Stats display (Gold, Wave, Lives)
- **Game Canvas (65%)**: Main play area with grid-based map
